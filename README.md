# Projeto Brasileirão Database

## Sobre o projeto

Sistema de banco de dados desenvolvido em MySQL com temática voltada ao Campeonato Brasileiro, permitindo o armazenamento e gerenciamento de informações fictícias sobre times, jogadores, partidas, classificação e estatísticas da competição.

O projeto foi criado com foco na prática de conceitos fundamentais de banco de dados relacionais, incluindo modelagem, relacionamentos entre entidades e manipulação de dados utilizando SQL.

Durante o desenvolvimento foram aplicados conceitos de:

* Modelagem de banco de dados;
* Criação de tabelas;
* Relacionamentos;
* Chaves primárias e estrangeiras;
* Integridade relacional;
* Manipulação de dados utilizando SQL.

Além disso, foram utilizados comandos SQL como:

* SELECT
* INSERT
* UPDATE
* DELETE

para gerenciamento e consulta das informações armazenadas no banco de dados.

---

## Tecnologias utilizadas

* MySQL
* SQL
* BR Modelo

## Estrutura do repositório

Neste repositório estão disponíveis:

* O arquivo ".sql" contendo toda a estrutura e comandos do banco de dados;
* O arquivo do "BR Modelo", utilizado para representar o modelo conceitual do banco de dados.

---

## Objetivo do projeto

O principal objetivo deste projeto foi desenvolver habilidades práticas relacionadas à modelagem e manipulação de bancos de dados relacionais, simulando um sistema de gerenciamento de informações do Campeonato Brasileiro.
