# Brasileirão Database

Projeto desenvolvido em MySQl com o objeto de praticar modelagem de banco de dados, construção de tabelas, relacionamentos, inserção, busca e remoção de dados.

## Sobre o Projeto

Sistema de banco de dados desenvolvido em MySQL com temática voltada ao Campeonato Brasileiro, permitindo o armazenamento e gerenciamento de informações fictícias sobre times, jogadores, partidas, classificação e estatísticas da competição.

O projeto foi criado com foco na prática de conceitos fundamentais de banco de dados relacionais, incluindo modelagem, relacionamentos entre entidades e manipulação de dados utilizando SQL.

### Comandos Utilizados

* SELECT
* INSERT
* UPDATE
* DELETE

### Tecnologias utilizadas

* MySQL
* SQL
* BR Modelo

## Estrutura do repositório

Neste repositório estão disponíveis:

* O arquivo ".sql" contendo toda a estrutura e comandos do banco de dados;
* O arquivo do "BR Modelo", utilizado para representar o modelo conceitual do banco de dados.
